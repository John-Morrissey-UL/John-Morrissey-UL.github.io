01

Discussion Network

The problem
Brightspace shows a discussion one thread at a time. It can't tell you whether students are talking to each other, or only to the lecturer.
What it does
Draws the whole board as a network: each person a dot, each reply an arrow, coloured by who wrote it. A board where staff do all the answering turns orange at a glance. The headline figure is the share of students who got a reply from another student, and it names the ones nobody replied to. A slider replays the term week by week.

02

Deadline Radar

The problem
Every module sets its own deadlines, so nobody sees when a programme piles its heaviest assessments into the same week.
What it does
Pick the modules and it plots every assignment and quiz window on one timeline, weighted by each item's share of the module grade rather than a raw count. A month, week and day grid flags the collision weeks, and special-access extensions appear as the second deadline they really are. Read-only.
Source on GitHub

Valence API · grade weighting · special access · saved selections · light and dark

Mock modules.
03

Class Faces

The problem
Learning a new class's names from a text classlist is slow, and the photos sit one profile at a time.
What it does
Turns the classlist into a searchable grid of faces for a visual roll call, or a printable face sheet for week one. Sort by first or last name, filter by group or role, and hover a face to jump to that student's Class Progress.
Source on GitHub

About

I work in educational technology at the University of Limerick, managing projects and looking for better ways to use our VLE, Brightspace (D2L).

Most of my time goes on the people who use it every day: lecturers setting up modules, administrators running the term, and the students on the other side. The tools on this page came out of that work. Each one started as a question someone asked that Brightspace's own screens couldn't answer quickly.

I share them openly because the same questions come up at every institution that runs Brightspace, and a single file that anyone can paste into a course is the easiest kind of tool to pass on.

What I work on

  • VLE innovation in higher education
  • Educational technology projects
  • Brightspace (D2L) tools and widgets
  • Learning analytics and data visualisation
  • Brightspace APIs, Python and Power Automate
  • Short explainer videos for staff

One file, nothing to install

Everything lives in a single HTML file. Paste it into a Brightspace page or widget and save. Nothing to compile or host.

Your login, your permissions

The tools use the viewer's own Brightspace session, so nobody sees anything they couldn't already see, and no passwords or keys are stored.

Works on any Brightspace

API versions and course details are picked up automatically. Nothing is tied to one university.

Read-only unless it says so

Reporting tools only read. The ones that change things, like grades or groups, say so plainly and show a preview first.
